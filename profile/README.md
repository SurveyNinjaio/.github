**[SurveyNinja](https://surveyninja.io/?utm_source=github&utm_medium=profile)** is an online survey maker: surveys,
quizzes, forms and polls with logic, reports and AI analysis of responses, in English, Spanish and Portuguese.
Here is everything you need to connect SurveyNinja to an AI assistant: the MCP server, ready-made skills and
configs for popular clients.

| Repository | What is inside |
|---|---|
| [**surveyninja-mcp**](https://github.com/surveyninjaio/surveyninja-mcp) | The MCP server `mcp.surveyninja.io` and ready-made skills: a survey from a brief, a check before launch, analysis of responses, a report you can send. Steps and configs for Claude, ChatGPT, Claude Code, Cursor, VS Code, Codex and Gemini CLI |

**Quick start in Claude Code.** The MCP server and every skill in one install:

```text
/plugin marketplace add surveyninjaio/surveyninja-mcp
/plugin install surveyninja@surveyninja
```

Every SurveyNinja plan includes the MCP server, Free too.
